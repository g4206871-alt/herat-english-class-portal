# سیستم آنلاین صنف انگلیسی پوهنتون هرات

این پروژه یک وب‌سایت واکنش‌گرا و قابل نصب روی موبایل است. محصلان بدون حساب کاربری می‌توانند تقسیم اوقات، اطلاعیه‌ها، وظایف و امتحانات، فایل‌ها و گروپ‌ها را ببینند. مدیران و ویرایشگران با حساب جداگانه وارد پنل مدیریت می‌شوند.

## محتویات پروژه
- `public/index.html` — صفحات سایت و پنل مدیریت
- `public/styles.css` — طراحی مناسب موبایل و کمپیوتر
- `public/app.js` — منطق سایت، دریافت اطلاعات و مدیریت محتوا
- `public/config.js` — تنظیمات اتصال دیتابیس
- `public/manifest.webmanifest` و `public/service-worker.js` — قابلیت نصب به‌عنوان وب‌اپ
- `supabase/schema.sql` — ساخت جدول‌ها، سطح دسترسی‌ها و فضای فایل‌ها

## مرحلهٔ اول: ایجاد دیتابیس رایگان
1. در [Supabase](https://supabase.com/) حساب بساز و یک پروژه ایجاد کن.
2. بخش **SQL Editor** را باز کن.
3. محتوای فایل `supabase/schema.sql` را کامل کاپی کن، در SQL Editor بگذار و اجرا کن.
4. از بخش **Project Settings → API** آدرس پروژه و کلید عمومی `anon` یا `publishable` را کاپی کن.
5. فایل `public/config.js` را باز کن و مقدارهای `SUPABASE_URL` و `SUPABASE_ANON_KEY` را با اطلاعات پروژهٔ خودت عوض کن.

**مهم:** کلید `service_role` را هیچ‌وقت در سایت قرار نده. فقط کلید عمومی را استفاده کن.

## مرحلهٔ دوم: ساخت حساب مدیر اصلی
1. در Supabase بخش **Authentication → Users** برو و یک کاربر با ایمیل و رمز قوی بساز.
2. در SQL Editor، ایمیل مدیر را در دستور زیر جایگزین کن و اجرا کن:

```sql
insert into public.profiles (id, display_name, role)
select id, 'مدیر اصلی صنف', 'admin'
from auth.users
where email = 'YOUR-ADMIN-EMAIL'
on conflict (id) do update
set role = 'admin', display_name = 'مدیر اصلی صنف';
```

3. برای ساخت حساب ویرایشگر دیگر، یک کاربر جدا بساز و نقش او را به `editor` تغییر بده. برای مثال:

```sql
insert into public.profiles (id, display_name, role)
select id, 'ویرایشگر صنف', 'editor'
from auth.users
where email = 'EDITOR-EMAIL'
on conflict (id) do update set role = 'editor';
```

دانشجویان عادی به حساب کاربری نیاز ندارند. هر کسی که حساب Auth بسازد به‌طور پیش‌فرض نقش `student` می‌گیرد و به پنل مدیریت دسترسی ندارد.

## مرحلهٔ سوم: آزمایش در کمپیوتر
اگر Python نصب است، ترمینال را در پوشهٔ `public` باز کن و اجرا کن:

```bash
python -m http.server 8080
```

بعد در مرورگر آدرس `http://localhost:8080` را باز کن. اگر دیتابیس تنظیم نشده باشد، سایت فقط حالت پیش‌نمایش را نشان می‌دهد.

## مرحلهٔ چهارم: نشر رایگان
می‌توانی فایل‌های داخل پوشهٔ `public` را در یک مخزن GitHub قرار بدهی و از **GitHub Pages** برای میزبانی فرانت‌اند استفاده کنی. دیتابیس، ورود مدیر و فایل‌ها توسط Supabase مدیریت می‌شوند. سپس آدرس نهایی سایت را در Supabase در بخش **Authentication → URL Configuration** به‌عنوان Site URL و Redirect URL تنظیم کن.

شرایط طرح رایگان و نیاز به تأیید حساب نزد ارائه‌دهنده‌ها تغییر می‌کند؛ پیش از نشر، شرایط روز را بررسی کن. این پروژه در حال حاضر هنوز آنلاین نشر نشده است.

## امکانات پنل مدیریت
- افزودن اطلاعیه
- ثبت وظیفه و امتحان
- ثبت تقسیم اوقات
- ساخت گروپ و فهرست اعضا
- بارگذاری فایل درسی تا ۱۵ مگابایت
- حذف موارد نشرشده

## پیش از استفادهٔ رسمی
- تقسیم اوقات و تاریخ‌ها را با استادان تأیید کن.
- فقط به افراد مورد اعتماد حساب و نقش `editor` بده.
- برای مدیر اصلی از رمز قوی و یکتا استفاده کن.
- فایل‌های حساس یا اطلاعات شخصی محصلان را به‌صورت عمومی نشر نکن.
